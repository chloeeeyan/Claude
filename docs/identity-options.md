# 第 5 项：游戏特色——已定：观众席 + 夜场剧团

**决定（2026-10-07）**：核心机制选「观众席」，主题选「夜场剧团」。已实现：

- 每一场台下 3 位观众（17 种喜好，暖场好说话、压轴最挑剔），选场时就能看到。
- 过关只看掌声（目标分数）；合了某位观众口味的那手牌当场打赏（$ 或这手 ×倍率），一场一次；三位全征服是「满场喝彩」。
- 6 张围绕观众的演员（托儿、刺头、经纪人、领掌人、返场、票房）。
- 全部改名：底注 → 第 N 夜；小盲 / 大盲 / Boss → 暖场 / 正戏 / 压轴；分数 → 掌声；小丑 → 演员；塔罗 → 道具；星图 → 剧本（剧目名）；商店 → 后台；优惠券 → 剧院改造。
- 平衡：模拟器普通难度胜率约 9%；完全不理观众约 2%，观众是核心而不是点缀。

下面保留当时的备选方案，供以后回顾。

---


现在的玩法骨架和 Balatro 很像，用的也是扑克术语（盲注、底注、同花、葫芦）。这有两个问题：一是在 Steam 上会被直接拿来和 Balatro 比，二是棋牌题材在微信小游戏这类渠道受限。
路线图第 5 项要做两件事：

1. 加 1–2 个**原创核心机制**，让玩家一句话就能说出「这游戏和 Balatro 哪里不一样」；
2. 把**主题命名**从扑克黑话里换出来。

下面每类给 3 个方向。每个方向都写了机制、一句话卖点、对现有代码的改动量，以及我的看法。你挑一个（或者组合），我来实现。

---

## A. 原创核心机制（选 1–2 个）

### A1. 「连载」：每一手牌是一格漫画
- 机制：一回合打出的几手牌排成一条漫画（最多 4 格）。相邻两格如果「接得上」（同花色延续、点数接龙、牌型升级），后一格的倍率乘以「连载加成」（×1.2、×1.5、×2）。
- 卖点：不只是凑一手大牌，而是**编排一回合的节奏**。弃牌和出牌顺序都变成策略。
- 和画风的契合：最高。现在的波普漫画风正好能把出牌区画成分格漫画。
- 改动量：中。计分要多一层「格间加成」，界面要加一条漫画格。新增一类小丑（「伏笔」「反转」「大结局」）。
- 我的看法：**首选**，和现有美术方向绑定最紧，宣传图也最好做。

### A2. 「夜场时钟」：时间段轮换
- 机制：每个底注分成「黄昏 / 午夜 / 黎明」三个时段，取代小盲、大盲、Boss。每个时段有一条全局规则（午夜：红色牌 ×2；黎明：最后一手翻倍……），小丑也分「夜猫子」「早鸟」两类，只在对应时段生效。
- 卖点：同一套小丑在不同时段表现不同，**阵容要跨时段搭配**。
- 改动量：中。改关卡结构和命名，Boss 规则复用，给小丑加时段标签。
- 我的看法：和「夜场」这个名字最贴，也顺便解决了「盲注」的命名问题。可以和 A1 叠加。

### A3. 「押注」：每手前下注
- 机制：出牌前可以押上一部分金钱，赌这手能拿到目标分的多少比例。押中按倍率返还，押错就亏掉。
- 卖点：把经济系统从「回合末拿利息」变成**每手都有风险决策**。
- 改动量：小到中。
- 我的看法：手感刺激，但「下注」在国内平台审核上更敏感，**不建议**作为核心。

## B. 主题命名（选 1 个）

现在用的「盲注 / 底注 / 小丑 / 塔罗 / 星图」，换成一套自己的世界观：

| 现在 | B1 夜场剧团 | B2 漫画编辑部 | B3 街头帮派 |
|---|---|---|---|
| 底注（8 个） | 第 N 夜 | 第 N 期连载 | 第 N 条街 |
| 小盲 / 大盲 / Boss | 暖场 / 正戏 / 压轴（压轴嘉宾） | 草稿 / 定稿 / 截稿日（主编） | 收保护费 / 抢地盘 / 老大 |
| 目标分数 | 掌声 | 人气 | 名声 |
| 小丑 | 演员 | 角色 | 小弟 |
| 塔罗 | 道具 | 分镜 | 纹身 |
| 星图 | 剧本 | 题材 | 招牌 |
| 优惠券 | 剧院改造 | 编辑部福利 | 地盘升级 |
| 商店 | 后台 | 编辑部 | 黑市 |

- **B1 夜场剧团**：和「鬼牌夜场」这个名字最贴，「掌声」做分数也直观。我的推荐。
- **B2 漫画编辑部**：和 A1「连载」机制天然一套，画风也是漫画，整体最统一。
- **B3 街头帮派**：风格最冲，但题材审核风险最高。

扑克本身的牌型（对子、顺子、同花）建议**保留**：这是玩家已有的知识，换掉反而增加学习成本。只换「关卡 / 货币 / 道具」这一层。

---

## 我的组合建议

**A1「连载」+ B2「漫画编辑部」**：机制、命名、画风三者是同一个概念，Steam 页面一句话就能讲清：「把扑克牌打成一部漫画连载」。
备选：**A2「夜场时钟」+ B1「夜场剧团」**，更贴现在的标题。

你回复编号即可（例如「A1 + B2」）。也可以只选机制或只选命名，或者说想要哪种感觉，我再出方案。
