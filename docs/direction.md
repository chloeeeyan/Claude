# 最终方向：Tough Crowd ·《别冷场！》

**决定（2026-10-09）**：目标是无预算做成能在 Steam 上架的独立游戏。这份文档记下已经定下的方向，后续开发都按这里来；要改方向，先改这份文档。

## 一句话卖点

**读场：台下坐着谁，就打什么牌。** 过关仍然看分数，但每场台下的观众口味不同、还会互相冲突，讨好谁、冷落谁，是每一手都要做的决定。

## 主题：1980 年代美国深夜电视秀

你是一档深夜牌局直播秀的主持人，演播室里坐着一群难搞的现场观众。收视率掉到零，节目就停播。

- **英文名**：*Tough Crowd*（脱口秀行话「今晚台下很难搞」，正好就是玩法）。
- **中文名**：《别冷场！》（主持人最怕的一句话）。
- 2026-10-09 快速搜过：Steam 上没有同名游戏，只有两个 2024 年 Global Game Jam 的 itch.io 小作品。上架前要再查一遍 Steam 和商标。
- 放弃的名字：Dead Air（已有 *Interference: Dead Air*）、Cue Cards（已有 *CUE Cards TCG*）、Laugh Track（2026 年已有同名情景喜剧游戏）、Read the Room（已有同名派对卡牌）。中文备选《看人下牌》。

## 风格规矩

**只用两种风格，各管一块：**

- **波普漫画画「现实」**：舞台、人物、卡牌、界面。现有的墨线、硬阴影、Ben-Day 网点全部保留。
- **蒸汽波只用在「屏幕里」**：CRT 扫描线、VHS 噪点、换台过场、日落渐变的节目单。规矩只有一条：电视里的东西才用蒸汽波。

从喜欢的游戏里只借气质，不照搬：

- **极乐迪斯科**：借文字的锋利。每种观众配一两句毒舌台词，被打动和被冷落时各说一句。只花文案成本。
- **斯普拉顿**：借高饱和配色和轻松的态度。
- **赛博朋克 2077**：只借讽刺。压轴是赞助商和电视台审查员（「本期禁止出红牌」）。不做霓虹赛博城市。
- **底特律：变人**：不借。

## 开发路线

每一项都走：`npm test` → `npm run build` → 浏览器验证四种尺寸（1366×640、1134×734、手机竖屏、手机横屏）→ draft PR → CI 绿后合并。素材只用 CC0 等可商用授权，记入 `docs/credits.md`。

0. ✅ **本文档**。
1. ✅ **换主题**：界面文字、标题、封面按上表换成深夜电视秀；规则、数值、存档都不动。先做这步，后面新写的观众文案就不用写两遍。
2. **第①阶段：读场做深**，拆成三个 PR：
   1. ✅ sim 机器人学会照观众打牌：选牌时把打赏的钱也算进价值，并输出每场打动几位观众、全场起立的比例。
      基准（n=800，普通，红色牌组）：会读场 9.6% 胜率、每场打动 1.47/3 位、全场起立 12%；不读场（`read=0`）9.4%、1.31/3、8%；空座（`aud=0`）2.3%。
      结论：现在的现金打赏（$1–3）太小，读不读场对胜负几乎没影响，观众的价值几乎全在 ×倍率打赏上。第 2 个 PR 要让「读场」真正值钱。
   2. ✅ 热度 0–3 档 + 口味冲突，观众台词，`SAVE_VERSION` 5 → 6 并写迁移：
      - 每位观众有喜欢（♥）和讨厌（✕），每场三位里至少有一对口味打架（讨好一个会惹恼另一个）。喜欢这手的人不会嘘。
      - 热度每场从「暖场 ×1」开始：有人喜欢 +1，没人喜欢 −1，每声嘘再 −1；这手牌按新热度乘：冷场 ×0.5 · 暖场 ×1 · 热烈 ×1.5 · 沸腾 ×2。全场起立直接沸腾。
      - 每位观众两句台词（被征服 / 喝倒彩），出牌时以气泡出现；选牌时预览谁会被征服（黄）、谁会嘘（红）、热度会变成多少。
      - 冷场罚得狠是故意的（游戏就叫《别冷场！》）。为保持胜率，目标分整体下调约 15%：`ANTE` = 250, 650, 1700, 3400, 6800, 13500, 23000, 36000。
      - 结果（n=800，普通，红色牌组）：会读场 9.0%、不读场（`read=0`）7.2%、空座 4.1%。读场的价值从 +0.2 个百分点升到 +1.8。机器人有 21% 的手是冷场。
   3. ✅ 重设 `HANDS` 数值：换成自己的表（原来和 Balatro 一模一样）——三条、顺子、葫芦加强，两对略降，顺子比同花值钱。
      n=800：会读场 8.5%、不读场 7.2%、空座 2.9%。
      **sim 的局限**：机器人只从手里现有的牌挑最高分，弃牌只会追同花，不会为了三条、顺子或观众口味去换牌，
      所以换了三套牌型数值，出牌分布几乎不变（高牌 25%、两对 20%、对子 19%、同花 14%）。各牌型之间的平衡要靠第③阶段的真人试玩来定，
      试玩数据里记录了每局各牌型的出牌次数（`stats.types`）。
3. **第②阶段：观众反应音效**：笑声、掌声、嘘声、冷场蟋蟀声、换台声。
4. **第③阶段：5–10 人试玩**，按 `docs/playtest.md`。**这是关卡**：结果不好就回头改，不往下走。
5. **第④阶段**：5 人候场选 3；压轴改成 VIP 观众（赞助商、审查员）；熟客（跨场次记得你的观众）；改造 15–20 个班底。
6. **第⑤阶段**：波普漫画 + CRT 屏幕层的美术、Steam 商店页、英文 Demo。
7. **第⑥阶段**：Tauri 外壳、成就、云存档。
