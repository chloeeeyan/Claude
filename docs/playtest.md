# 试玩方案：20–30 人（路线图第 10 项）

## 目标
回答 4 个问题：
1. 新手能不能**不看说明**就打完第一个盲注？（新手教学有没有用）
2. 大家**在哪一关放弃**？（难度曲线）
3. 哪些小丑**从来没人买**、哪些**每局都买**？（平衡）
4. 玩完一局之后**还想不想再开一局**？（留存的直接信号）

## 招人
- 20–30 人，一半玩过 Balatro 或卡牌构筑游戏，一半没玩过。
- 至少 1/3 用手机（横屏、竖屏都要有人试）。

## 流程（每人约 40 分钟）
1. 发网址，什么都不解释。
2. 请对方自由玩 30 分钟，至少打 2 局。
3. 玩完以后，在游戏里打开「图鉴 → 收藏 → 试玩数据 → 导出文件」（手机上可以用「复制文本」），把文件或文本发回来。
4. 填下面的问卷（5 分钟）。

游戏里的试玩数据只存在玩家自己的设备上，不会自动上传。导出内容包括：每局的牌组、难度、走到第几关、被哪个 Boss 打败、每关用了几手、最终的小丑和优惠券、用时，以及新手教学进行到哪一步。

## 问卷
1. 第一局里，你什么时候明白「这游戏怎么玩」了？（第一手 / 第一个盲注后 / 第一次进商店后 / 还是不太明白）
2. 哪一刻最爽？哪一刻最想关掉？
3. 有没有哪张小丑或哪个 Boss 让你觉得「这不公平」或「看不懂」？
4. 画面上有没有找不到的按钮或看不清的字？（手机玩家重点答）
5. 如果这个游戏在 Steam 卖 ¥30，你会买吗？为什么？
6. 0–10 分，你会推荐给朋友吗？

## 汇总
把收到的 JSON 放进同一个文件夹，交给 Claude 汇总。重点看：
- 每个底注的流失率，和模拟器的曲线对比；
- 每个 Boss 打败玩家的次数；
- 每张小丑的出现次数和购买次数；
- 新手教学停在哪一步；
- 每局平均时长。
